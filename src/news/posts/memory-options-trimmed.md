---
title: "M4 Pro loses 64 GB, M3 Ultra drops to 96 GB only"
date: 2026-05-17
summary: "The M4 Pro's top memory tier is gone, and the M3 Ultra now only offers 96 GB."
categories: ["m4-pro", "m3-ultra"]
---

Two more memory configurations have been withdrawn, following the [M3 Ultra Mac Studio losing its 512 GB option](/news/m3-ultra-drops-512gb/) a couple of months ago.

The [M4 Pro](/chips/m4/pro/) — both the [12c CPU / 16c GPU](/chips/m4/pro/12-16/) and [14c CPU / 20c GPU](/chips/m4/pro/14-20/) parts — in the [Mac Mini](/devices/mac/mac-mini/) no longer offers 64 GB. It now tops out at 48 GB, with base models featuring 24 GB. Bandwidth is unaffected at 273 GB/s across a 256-bit bus.

The [M3 Ultra](/chips/m3/ultra/) in the [Mac Studio](/devices/mac/mac-studio/) has lost 256 GB, leaving **96 GB as its only memory option** on both the [28c CPU / 60c GPU](/chips/m3/ultra/28-60/) and [32c CPU / 80c GPU](/chips/m3/ultra/32-80/) parts. A 1024-bit bus at 819.2 GB/s now feeds a maximum of 96 GB.
